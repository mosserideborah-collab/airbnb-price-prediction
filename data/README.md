# Data

The CSV files are not versioned (≈ 95 MB). Put them in this folder:

| File | Rows | Content |
|---|---|---|
| `airbnb_train.csv` | 22,234 | 27 features + target `log_price` |
| `airbnb_test.csv`  | 51,877 | same features, no target |

The data comes from the public *Airbnb listings in major US cities* dataset (Kaggle), provided as a course project at ESILV.
